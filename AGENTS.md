# Repository Instructions

## Writing Standard

Use ASD-STE100 Simplified Technical English for all technical prose in this repository.

This rule applies to these files and text fields:

- `SKILL.md` files
- references and examples
- evaluation prompts and expected behaviors
- `agents/openai.yaml` interface text
- the repository README
- code comments, docstrings, and user-facing diagnostic text

Use these writing rules:

- Use short, direct sentences.
- Use active voice.
- Put one instruction in each sentence.
- Use one term for one concept.
- Use the same term in all files that describe that concept.
- Do not use contractions.
- Do not use idioms, metaphors, or promotional language.
- Do not use `should` for a requirement or recommendation. Use `must` for a requirement. Use an imperative verb for an instruction or recommendation.
- Keep exact technical names, identifiers, commands, paths, and quoted user text when accuracy requires them.
- Preserve a user prompt in an evaluation when its natural wording is part of the test.

Review this style during normal editing and review. Do not add automated language checks unless a repository owner requests them.
